# Política de Privacidade — Gerador QR

**Última atualização:** 23 de maio de 2026

## 1. Informações Gerais

O Gerador QR é um aplicativo gratuito para geração de códigos QR. Esta política descreve como tratamos as informações dos usuários.

## 2. Dados Coletados pelo App

O Gerador QR **não coleta, armazena nem transmite** nenhuma informação pessoal para servidores próprios. Todos os dados inseridos (chave PIX, endereço, nome de rede WiFi, links) são processados **localmente no dispositivo** e usados exclusivamente para gerar o QR code.

### Acesso à Galeria
O app solicita acesso à galeria de fotos apenas quando o usuário opta por adicionar um logo personalizado ao QR code. A imagem selecionada é usada somente para exibição local e não é transmitida para nenhum servidor.

## 3. Publicidade (Google AdMob)

O app exibe anúncios através do **Google AdMob**. O Google pode coletar e usar dados para personalização de anúncios conforme sua própria política de privacidade. Para mais informações, acesse:
https://policies.google.com/privacy

Para optar por não receber anúncios personalizados, acesse as configurações de anúncios do Google em seu dispositivo.

## 4. Permissões Utilizadas

- `READ_MEDIA_IMAGES` / `READ_EXTERNAL_STORAGE` — acesso à galeria para seleção de logo (opcional)
- `INTERNET` — necessário para exibição de anúncios
- `ACCESS_NETWORK_STATE` — verificação de conectividade para anúncios

## 5. Crianças

O app não é direcionado a crianças menores de 13 anos e não coleta intencionalmente dados de menores.

## 6. Alterações nesta Política

Eventuais atualizações serão publicadas neste repositório. O uso continuado do app após alterações implica aceitação da nova política.
